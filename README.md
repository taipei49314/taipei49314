# 👋 Nelson

Building AI-agent systems in Taiwan — multi-agent research desks, local-first tools, and creative automation.

我用 AI agent 蓋小型「研究公司」:多模型委員會、紙上交易、證據鏈、桌面小工具,盡量全部在本機跑。

## 🧭 原則 / Principles

- **Paper-only 紅線** — 交易相關專案永不接券商、永不下真單,research only。
- **Local-first / 免費優先** — 能用本地模型(Ollama / Qwen)就不動雲端金鑰。
- **證據優先** — 結論要能回溯出處;資料不足就標 `Insufficient data`,不腦補。
